# FR3: 同じ点での局所動力学微分の再利用

## 変更

RoboKotsで同じ線形化点の積を繰り返す場合、動力学の局所微分をキャッシュする。
最適化変数に対する全体ヤコビアンは構築せず、時刻ごとの
「トルク出力 × 局所運動座標」の小行列を保持する。

- 同じフィールドのJvが `DoF * used_order` 回必要になった時点で、
  単位行列をRHSとするネイティブ呼出しを1回行い、局所微分を作る。
- 以降のJvと合算Jᵀvで同じブロックを共有する。
- 点・時刻列・重力・モデル次数などのoutward状態が変われば破棄する。
- 保存上限32 MiB。行列RHS非対応のプロバイダーは元のベクトル積へ戻る。
- 前処理、内部許容値、反復上限、ラインサーチは変更しない。

FR3の場合は局所運動35成分、トルク3種類21成分×201時刻で、
キャッシュは約1.13 MiB。積の少ない問題では構築しない。
これは古い点で計算した近似ヤコビアンの再利用ではない。
ただし浮動小数点の演算順序は変わる。

## 測定条件

[直前の測定](krylov_fr3_acceleration.md)と同じFR3v2、182変数、8442残差、
トルク3種類、200区間、30制御点、order=5。
random weights seed=0、BLASスレッド数1。外側上限60、勾配閾値1e-8、
内部許容値1e-10、内部上限364。各方式1回の計測。
ユーザーの実際の入力との一致は未確認。

## 最初の1反復：既定Krylov

同一プロセスで局所キャッシュなし→ありの順に測定。
Jvの3フィールド共有化は両方に有効。

| 項目 | キャッシュなし | あり |
|---|---:|---:|
| 時間 | 12.50秒 | 3.71秒 |
| ネイティブJv呼出し | 365 | 35 |
| ネイティブ合算Jᵀv呼出し | 368 | 37 |
| 内部反復 | 364 | 364 |
| 相対正規残差 | 2.408e-4 | 1.244e-4 |
| 更新後目的関数 | 8.76046423046e10 | 8.75679741356e10 |

約3.4倍高速化。キャッシュ構築は計時内。
両方とも内部上限で打切りのため、丸め誤差による反復軌跡の変化が
最終ステップにも現れた。更新後目的関数の相対差は約0.042%。
更新結果がビット単位で同一になる変更ではない。

## 全体比較

| 方法 | 時間 | 外側更新数 | 最終目的関数 | 最終勾配∞ノルム（密J） |
|---|---:|---:|---:|---:|
| 既定Krylov＋局所キャッシュ | 231.75秒 | 56 | 28.3958407244344 | 5.1434e-5 |
| normal＋局所キャッシュ | 88.28秒 | 31 | 28.3958407244377 | 4.1329e-5 |
| normal、局所キャッシュなし（前回） | 208.93秒 | 30 | 28.3958407244373 | 2.4011e-5 |

normalで約58%の時間短縮（前回計測との比較）。最終目的関数は一致した。
今回の2方式は同一プロセスでnormal→既定Krylovの順に計測しており、
この入力ではnormalの方が約2.6倍速い。通常GNの前回156.65秒も下回った。
どの方式も `stalled` / `line_search_retry_limit` で、勾配閾値1e-8は未達。
更新回数や勾配の差を隠して、同一軌跡の高速化や厳密収束とはみなさない。

モデル構築・コンパイル・制約削減は計時外。
計時後に密Jで最終勾配を確認した。
既定Krylovのキャッシュなし全体測定は今回繰り返していない。
以前の約1758秒という測定は実行時の速度変動があるので、高速化率の分母にしない。
通常GNの156.65秒も前回計測であり、今回の同一プロセス内比較ではない。

## 採用しなかった案

全正規行列の前処理を5点ごとに更新する試作も実行したが、序盤に
内部反復の上限到達が増えた。25更新付近で約283秒、勾配は約4.44e6のため
計測を中断し、変更を取り消した。実装に古い点の前処理を再利用する変更は含めない。

## 再現

RoboKotsを導入した環境で実行する。

```bash
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
python developer/benchmarks/krylov_fr3_acceleration.py \
  --doc-script /path/to/ijrr_structured_jacobian/work/doc_ioc.py \
  --max-iters 1 --variants uncached shared --output /tmp/fr3-cache-first.json

PYTHONPATH=. OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
python developer/benchmarks/krylov_fr3_acceleration.py \
  --doc-script /path/to/ijrr_structured_jacobian/work/doc_ioc.py \
  --variants normal shared --output /tmp/fr3-cache-full.json
```

`uncached` はベンチマーク中だけ局所キャッシュを無効化する。
`shared` は今回の既定Krylov、`normal` は明示的に全正規行列前処理を選ぶ。
比較目的で全方式の局所キャッシュを止める場合は `--disable-motion-cache` を使う。
[生データ](krylov_fr3_motion_cache_results.json)に入力ハッシュ・履歴・内部診断・API回数を保存。

## 検証

関連テスト333件、ネイティブRoboKotsテスト12件成功。

ネイティブテストでは、キャッシュ構築前後のJv・Jᵀvの密Jとの一致、
点の変更による無効化、行列RHS非対応時のフォールバックを確認。
全体の密ヤコビアン構築を禁止したソルバーテストも継続して通過した。
