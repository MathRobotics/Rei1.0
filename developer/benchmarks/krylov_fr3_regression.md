# Krylov ラインサーチ版の性能修正

2026-09-27。`d2189d2` の対角前処理から、アフィン残差の Gram 行列全体を
使う前処理へ変更した。変数間の相関を保持し、固有分解は再利用する。
既定の内部許容誤差 `1e-10` と次元に応じた反復上限は維持した。

また CGLS の内部残差を `-g - J.T @ (J @ h) - damping*h` として計算する。
非零残差の停留点付近で、`r + J @ h` の形成によって小さな補正が失われる
ことを避ける。これは内部許容誤差を緩める変更ではない。

## 条件

- 外部プロジェクト `ijrr_structured_jacobian/work/doc_ioc.py` の順問題のみ。
  `--random-weights`、seed 0、FR3v2、200区間、30制御点、order 5。
- 等式制約削減後182変数。同じ初期値、`tol_grad=1e-8`、既定の
  `inner_tol=1e-10`、内部上限364回。通し計算は `max_iters=60`。
- 外部プロジェクトの Python 環境を使い、`PYTHONPATH` で Rei の実装を切替。
  `OPENBLAS_NUM_THREADS=1`、`VECLIB_MAXIMUM_THREADS=1`。
- 時間は `solve` 呼出し全体。モデル読込み、コンパイル、制約削減は除外。
  履歴と verbose は有効。各条件1回の診断測定であり、統計的な速度保証ではない。

修正前・最終実装の順に連続して再測定した。

|---|---:|---:|---|---:|
| `d2189d2` | 17.03 | 364 | max_iters | 278754.4795514457 |
| 最終実装 | 2.33 | 47 | converged | 643495.3128069157 |

最初の1反復は約7.3倍速くなった。修正前は内部上限に到達していたため、
求めた方向と反復後の目的関数は異なる。この倍率は同じ解へ到達するまでの
総時間の倍率を表さない。先の測定では修正前9.34秒だったため、絶対時間には
測定間の変動がある。

## 任意の適応精度

`inner_tol=None` を明示した場合のみ、初期の内部精度を緩める。
FR3 の試行では序盤は軽くなったが、目的関数約2230の別の経路へ進んだため、
途中で停止した。収束・総時間の改善実績とは扱わず、既定値には採用しない。
相関の強い合成問題では固定精度・適応精度の両方について、少ない内部反復での
収束、前処理の再利用、明示的な反復上限の遵守を回帰テストで検証している。
